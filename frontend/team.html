About the Project

WakeDrive is a real-time driver drowsiness detection and monitoring system developed to improve road safety and reduce fatigue-related accidents.The main objective of this project is to build a practical, intelligent, and user-friendly driver assistance system that helps prevent accidents and enhances safe driving.
